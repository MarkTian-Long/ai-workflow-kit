# 可编辑流程图小包

需要从自己的输入制作、离线导出和检查更多图时，使用完整的 [create-document-visuals Skill](../../skills/create-document-visuals/SKILL.md) 及其[安装说明](../../docs/document-visuals.md)。本目录继续提供轻量图样，不要求安装 Skill。

用于把步骤、责任或状态说清楚。先选要回答的问题，再取一个合成例子改写；不要求每份报告都画三种图。输入是已确认的步骤、角色、规则与未知，输出是可编辑 Mermaid 图源及离线 SVG 预览。

| 想回答的问题 | 图源 | 离线预览 |
| --- | --- | --- |
| 先做什么，何时分支，返工回哪里？ | [主流程](main-flow.mmd) | [主流程预览](main-flow.svg) |
| 谁负责什么，在哪里交接和检查？ | [角色协作](role-collaboration.mmd) | [角色协作预览](role-collaboration.svg) |
| 对象有哪些状态，什么事件让它迁移，异常如何结束？ | [状态及异常](states-and-exceptions.mmd) | [状态及异常预览](states-and-exceptions.svg) |

使用前看 [流程图制作 SOP](制作SOP.md)。`.mmd` 是纯文本，可用编辑器直接修改；有 Mermaid 支持的工具可另行渲染。`.svg` 可在浏览器或支持 SVG 的查看器中离线打开，无外链字体、图标、脚本或网络依赖。SVG 的布局由本包原生绘图生成，与 Mermaid 表达相同节点、边、条件和责任；其他渲染器的布局可以不同。

改动业务输入时，同时更新对应文字、图源与预览；不能只改 SVG 或把旧预览当新事实。三个例子都是原创中性合成资料，按集合根目录的 MIT 许可提供，不代表任何真实项目的制度或验收。采用者需核对自己的规则与权限；本包没有自动化业务执行能力。
