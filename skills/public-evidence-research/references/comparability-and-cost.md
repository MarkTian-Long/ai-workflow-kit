# 条件化金额比较与成本责任

只有研究包含金额、授权、采购或TCO时阅读；不适用于普通文献观点整理。

## 每条价格先回答七个问题

1. 买的是哪种任务：专业内容审查、服务过程质检、数据入口、识别能力、整套平台、人工复核、定制开发还是维保？
2. 谁买、谁用：买方、最终业务使用方和供应商法定主体/原厂/集成商分别是谁？
3. 采购到了哪个阶段：预算、最高限价、候选、结果、合同、验收？是否属于前轮、二轮、包件或增购？
4. 运行在哪里：SaaS、公有云、私有云、本地化、混合部署或未知？“信创”不自动等于本地私有化，“客户有GPU”不等于GPU随软件交付。
5. 得到什么权利：一次性/永久/年度、源码/可执行程序、集团/实例/分支、受检员工/质检员/登录用户、容量与并发？这些计量轴不能互换。
6. 包含哪些费用：标准软件、部署、规则/场景适配、集成、定制、维护、人工运营、模型、算力、存储、第三方数据和通信是否已含，谁承担？
7. 有什么期限与验收：建设、免费维保起算、授权续费、资源包有效期、服务SLA、业务规则和样本验收谁签字？

缺少业务任务、范围、部署、权利或主要包含项时，不建立“直接纯许可同条件区间”，但仍可纳入**功能/资源、费用结构、条件性建设包或待核金额**。可比性按当前问题判，不给厂商永久的统一等级。

## 不做这些推算

- 不把一个软件＋录音＋通话＋人工运营的总包直接换算成每分钟、每席位或每年**软件单价**；
- 不把预算/限价/候选与成交混算均价，也不把不同轮次旧限价继承给新结果；
- 不用两个不同项目的维保和初建价格相除得到市场维保率；
- 不把软件永久许可、三年免费维护、合同三年、系统三年后实际替换视为同一事件；
- 不将同一底座、权限、人审或已含维护在增购包里重复计费；
- 不因支持文本+图片+语音+视频就宣称声音/画面/字幕关联，也不因ASR/关键词就宣称完整金融服务流程质检。

**若原文已给单价**（每笔、每条、每人月、每分钟），保留原始数量和单位及地点/时长/驻场/质量责任条件。不同作业口径分别记录；不机械统一折算。

## 首期、续期与条件性三年费用

按需用下列结构核对，不强制提供完整数字：

| 费用 | 首期/续期核对 |
| --- | --- |
| 许可/订阅 | 许可证对象、版本、永久/年度与可用量，续期权利 |
| 部署及集成 | 本地化、迁移、信创、双活、培训、客户自备条件 |
| 规则/场景与专业内容 | 初始配置、持续规则更新、法规模型/第三方数据 |
| 算力/存储/通信 | GPU、ASR/OCR、音视频流量、留存/灾备及规模变化 |
| 人工运营/复核 | 按件、小时、质检员、人天及最终业务裁决责任 |
| 维护与增购 | 免费期从什么验收事件起算、期间包含的升级、期后服务基数、新场景与已含功能抵扣 |

三年TCO只有在**适用的三年窗口、各必要费用、资源归属、免费期起点、续期/用量条件**足够时计算；否则展示已知项及缺口。若要做情景估算，必须另标假设，不冒充合同值。

## 反例和验收

每种包装至少寻找一个有用反例：独立能力许可可能需要复杂接口责任；共享底座可能与客户已有底座重复；统一总包可能掩盖第三方资源和维护。人工评分、复检、申诉、规则/模型持续服务和责任主体应从实际需求/合同/验收分别标注，不能拿厂商准确率或POC演示替代真实质量结果。
