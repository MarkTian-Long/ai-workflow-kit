# 规划规则

## 约束优先

将相对日期转成明确日期，使用目的地当地时区；账号估计位置不代表出发点。硬约束包括已购返程与固定预约；偏好包括早起、步行、住宿和体验；工作假设必须可见。已定顺序直接检验，不强造多个方案。

先比较少量路线骨架。门到门预算包括到上车点、等车、乘车、换乘/停车、出站和入口步行。酒店先定区域，再比较实际入口、夜间交通、床型、早餐、套票、取消条款与总价。照片好看或临近景区不能证明步行便利。

## 每日行李闭环

携带者 → 寄存点 → 可接收日期、时段与尺寸 → 游览 → 取件点、截止与取件时间 → 下一段交通。到达日尚不能入住也要处理。若行李留酒店，不能把景区结束后直达车站写成可执行方案。换顺序仍须检查两天的寄存；未知条件不能被地图上的顺路掩盖。

## 时间、体验与预算

同一时间轴容纳吃饭、休息、排队、取物和转场。游湖总时长与船上时长分开；多区景点优先独特核心体验，不因套票全包就全部安排。早起、爬坡、天气暴露和长途驾驶应合并判断。

离场时点 = 固定发车/起飞时点 − 计划到站/机场提前量 − 交通预算 − 等车/换乘预算 − 取物/离场预算。提前量不是运营方官方截止，须分别标注。使用完整日期计算跨日行程。延误删可选项目，不靠超速或少休息补回。

费用明确币种、单价、数量、单位和状态；每人、每间每晚、每车、每天租车及整组分开。套餐内部项目只计一次；币种不同先核验换算，不能直接相加。未知金额单列，不把已知小计称完整总价。

## 天气与调整

天气对应活动时段和地点。登高看能见度、雨和湿滑；游船看风与雷电；室内/混合活动可作备选。为核心活动明确照常、缩短、替换、取消或等公告的条件和复核时点。提醒阈值不是停航标准；数据缺失保持未知，不推导低风险。

自驾另算驾驶者状态、连续驾驶、休息、山路夜路、停车、取还车及加油。预算未知时不要把每天都塞满当作默认。旅行后只有实际反馈才回写真实耗时和偏好；私人偏好不进入公开方法。
