# 证据规则

## 记录什么

每个会改变决定的事实记录：内容、状态、来源、checked_at、valid_for；可得时另记 issued_at 和失效条件。查询时间不是发布时间。没有来源发布时间就写未知，不补造日期。

| 状态 | 使用边界 |
| --- | --- |
| verified | 已查看适用的原始证据；不表示已预订或永不过期。 |
| user_provided | 用户当前订单、截图或明确说明；保留它的适用范围。 |
| estimate | 排程预算、价格估算；说明口径，不称实时报价或实测。 |
| unknown | 尝试合理渠道仍未核实；写明影响和下一步。 |
| conflict | 来源冲突未消除，决定仍有条件。 |

按事实选来源：个人预订看有效订单；停航闭园看运营公告；坐标、道路看地图；商品包含项和库存看对应日期的订票页；评价只用于体验线索。搜索摘要是线索，不能替代商品条款。当前已确认取消的订单不能因旧截图而恢复成 booked。

## 缺口与冲突

先看原始运营来源，再尝试一个独立来源或已具备的地图、浏览器渠道；记录尝试及停止原因。登录才能见到的库存写需登录核验；没有电话能力时提供待问内容，不称已致电。新的来源也要核对是否同景点、同入口、同票种和同适用日期。

优先核验：船票是否含门票、预约是否锁定时段、最后进场与最后一班交通、寄存尺寸及取件截止、酒店到真实入口的步行距离。未核实不以更多小数位制造确定性；直线距离不得变成道路里程或车程。

动态信息临出行再查；政策、健康和安全建议需要适用的一手来源，不能由本方法替代专业判断。旅行事实与网页接口事实分别核实。
