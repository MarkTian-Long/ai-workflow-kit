## 可复现命令

在仓库根目录：

```sh
python -m unittest discover -s skills/travel-planning/evals -p 'test_*.py' -v
python skills/travel-planning/scripts/check_trip.py skills/travel-planning/assets/synthetic-trip.json
```

套件依赖 Python 3.10+ 标准库，不联网。合成数据返回已知小计2160、人均1080、目标到站16:40、开始离场15:20；都是教学数值。新增行为或修改规则后重新运行适用测试，不累加历史次数为效果证据。

公开内容逐文件核对：不含真实订单、个人联系方式、私密页面链接、账号配置、API密钥、旅行者私人画像或第三方代码。公开回执以仓库提交、完整文件树及读取结果为准；本记录不提前声称目标网页的匿名访问成功。
