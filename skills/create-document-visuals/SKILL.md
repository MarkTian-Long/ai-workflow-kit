# 文档视觉化

先确定读者要回答的问题，再选择图型和实际可用引擎。保留唯一可编辑源，图片不能替代精确规则、数字、引用和验收条款。

## 选择路线并按需读取

| 当前任务 | 路线与本次需要读取的资源 |
| --- | --- |
| 简单线性步骤，文字已经清楚 | 保留短列表，不为有图而增加工作流 |
| 顺序、判断、返回回路、阶段分区 | 默认现有 Mermaid-lite；读 [流程图指南](references/flowchart-guide.md) |
| 跨角色交接、层级、系统分层或自动布局难以阅读 | 读 [SVG 布局指南](references/svg-layout-guide.md)，以可编辑 SVG 显式布局；按需使用其模板与样式参数 |
| 原生时序、状态机、实体关系图 | 读 [标准 Mermaid 路线](references/mermaid-standard.md)，显式使用独立本地引擎；不把标准语法交给 Mermaid-lite |
| 界面截图编号标注 | 原截图只读；按 SVG 布局指南添加独立标注层和编号解释表 |
| 指标、趋势、分布、精确比较 | 使用数据分析/可复现图表能力；本 Skill 不手绘数字或替代计算 |
| 概念、封面、氛围插图 | 读取当前可用 imagegen Skill；仅公开或获准脱敏内容，不用生成式图片承载精确业务关系 |

制作前只读命中路线的指南。实际保存、嵌图、交付或验收时，再读 [共享工作流](references/workflow-reference.md)；不要默认全读所有图型或参考。明确图型但引擎不支持时，说明限制并选择语义等价路线，不能静默丢弃语法。

## 所有路线共用的边界

- 明确父文档、输入主版本、目标输出和视觉用途：证据、解释或装饰；原件与原始截图只读。
- 公司/客户事实默认本地处理。代码图、SVG、PNG、PDF 离线渲染；不得上传到在线绘图服务或使用远程资源热链。图片生成只发送授权范围内内容，不记录密钥。
- 保持已确认业务分支、责任与关系；样式优化不授权改变规则。未知事实不为满足模板节点数而补造。
- 已认可的参考风格优先。同组图统一形状含义、文字层级和颜色语义；颜色同时配文字或线型。
- 一张图在实际阅读比例下不清楚时，拆为概览和局部，不用缩字号硬塞。

## 生成和检查

1. 整理主体、动作、条件、结果、异常和返回目标；只有影响当前表达的缺口才向用户确认。
2. 选择路线和唯一源。默认保存到父文档 `assets/<稳定视觉名>/source`，导出到同级 `export`，源和导出逻辑版本一致。 已有图重绘、横竖版切换或关系压缩时，先读 [关系保真检查](references/graph-preservation.md)，冻结已确认基线；按需使用离线关系检查器，其结果不代替真实箭头和最终容器验收。
3. 使用对应渲染命令。现有 `diagram` 保持 Mermaid-lite 行为；`mermaid` 是显式新增路线；`image` 和 `pdf` 继续承担转换。具体能力、命令和依赖见所选指南及共享工作流。
4. 对实际交付 SVG 运行 `check-layout`，按目标阅读宽度检查；普通桌面文档默认只验桌面，明确移动端需求或发现问题时再加窄屏。脚本覆盖不完整时保留 `structural-only` 或具体限制，不伪报视觉通过。
5. 自动几何检查不能替代业务语义和最终容器目视核对。对照分支、回路、人工边界和业务阅读顺序，检查中文、条件标签、字号、裁切、遮挡和连线；确定性缺陷修正后重渲染，启发式疑点人工裁决。

## 嵌图与交付

重要图保留图源引用、描述结论的替代文本、图注和必要文字兜底。精确图优先 SVG，PNG 为兼容版本；PDF 仅任务需要时生成。受管成果、多图或需复用交付时按共享工作流维护 visual manifest，单张轻量图不因缺清单失败。

报告实际图型/引擎、唯一源、导出与检查结论和真实限制；失败不创建占位图或失效引用。项目状态按父文档规则归位，不把客户节点、截图和运行记忆写回共享 Skill。
