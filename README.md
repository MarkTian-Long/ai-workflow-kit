# ai-workflow-kit

一些帮助人和 AI 协作的小工具与方法，按想做的事挑一个用即可。首批固定快照（2026-10-15）包含两项可单独采用的 Skill 和一份无需安装的 SOP，不要求整套接入。

| 你想做的事 | 选这个 | 输入与用法 | 得到什么 | 限制 |
| --- | --- | --- | --- | --- |
| 把一次会话的成果、待办保存好，再按需要归档或续接 | [session-closeout Skill](skills/session-closeout/SKILL.md) | 给出任务材料和本次范围；使用 `$session-closeout` 说明只保存、归档或新开续接 | 核验后的成果入口、明确待办及实际会话操作结果 | 保存需要可写正式位置；创建/归档需要宿主原生工具和相应授权 |
| 开放问题还没想清楚，想先拆解再决定方案 | [structured-analysis-discussion Skill](skills/structured-analysis-discussion/SKILL.md) | 提供目标、已定选择、约束和已有证据；使用 `$structured-analysis-discussion` 提出决策问题 | 关键条件、方案覆盖、反例、未知及可行动的建议 | 仍在验证方法收益；简单问答和已确定的单点执行不套流程 |
| 不安装 Skill，也想把当前会话交给下一次继续 | [一页会话交接 SOP](sops/session-handoff.md) | 按步骤核对已有材料，复制其中的自然语言请求并补充范围 | 最小正式交接和可继续推进的旧/新会话入口 | 缺少原生能力时只完成可安全执行的保存，保留旧入口 |

## 怎么开始

SOP 直接打开使用。Skill 可先让 Agent 明确读取选中的 SKILL.md，在隔离任务中处理一个合成请求；确认适用后，只复制所选完整目录到宿主支持的 Skill 位置。遇到同名运行 Skill，先保留原件并审阅差异，避免覆盖自己的适配。目录各自带齐必要 references，无须另一个 Skill、私人画像或全局规则。

两项 Skill 均允许宿主在适用时自动选择（`allow_implicit_invocation: true`）；文件存在、被发现、实际命中和执行成功需分别核验。analysis 的 `validating` 说明方法收益仍在验证，允许按边界使用，不是 Codex 官方启停开关。

本集合没有安装脚本、后台任务、账号或连接配置，也不安装 STORM、DSPy、Promptfoo。宿主的有效规则和当前用户授权优先；文本方法不能凭空提供工具能力或扩大权限。

## 维护方式

本仓库先作为固定发布快照；通用正文的唯一维护源仍在发布者现有本地正式源。本轮不迁移运行主源，也不改变本机运行行为。通用修订先回到唯一维护源，经核验后生成下一快照，避免两边平行手改。以后如需改为仓库主源，另行完成迁移；回滚使用前一固定快照及安装前原件。

以后可按真实使用需求加入 SOP、模板或小脚本；每个小件都应说清用途、输入、用法、结果和限制，不为分类完整先建空目录或通用大框架。
