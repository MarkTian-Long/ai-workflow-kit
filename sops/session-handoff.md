# 一页会话交接 SOP

用途：不用安装 Skill，也能把当前会话的成果与待办交给下一次继续。输入是本次任务的正式材料、当前决定和明确的会话范围；结果是可读回的正式交接与实际可用的入口。项目规则、敏感资料边界和用户授权优先。

## 最小步骤

1. **明确动作和范围。** 默认只处理当前会话；分别判断是否仅保存、是否归档、是否新开。整组交接只包含已有派发记录确认的成员，不凭相似标题推测范围。
2. **核对并保存增量。** 复用已有正式主位置，写清已完成及验证、待办的责任/阻塞/触发、关键决定与权限边界、材料入口及下一动作。重要纠正和可复用内容按既有共用资产处置；不复制完整聊天或敏感配置，不重做已经通过的工作。
3. **实际读回。** 核对正文、入口、待办及适用边界。只有聊天摘要或链接存在，不能算保存/交接已经完成。仅要求保存时，到这里报告实际结果并保持原会话。
4. **需要新会话时再创建。** 用宿主原生工具创建并核验归属；让新会话实际读取正式交接，准确复述已完成、待办、决定、边界和下一动作。记录本次读回对应的交接版本；关键内容变动后补读，复用已建会话，不重复创建。
5. **最后执行已获授权的归档。** 新开续接模式必须等新会话建成、归属正确且读回通过，再归档指定旧会话并核验实际结果。缺原生工具、创建失败或读回未通过时保留旧入口，说明剩余动作与触发；不拿 Prompt 或模拟结果冒充会话操作。

## 可复制的自然语言请求

只保存、下次继续：

> 请沉淀当前会话。复用本任务的正式主位置，核对已完成成果与验证、待办的责任/阻塞/触发、关键决定和边界、材料入口及下一动作；保存后实际读回。重要纠正与可复用内容按已有资产处置，保持当前会话，不归档、不新建。

保存、归档并新开续接：

> 请把当前会话沉淀归档，并新开会话继续。先保存并读回正式交接，再用原生工具创建和核验新会话归属，让新会话实际读回并准确说明现状，最后归档旧会话并核验。缺原生能力或读回不通过时保留旧入口，报告实际完成与剩余动作，不伪造创建或归档。
